# Project notes

TSE Golden Demos is a single-page launcher for ThoughtSpot demos. See
[README.md](README.md) for the `demos.json` field reference.

- **Data-driven.** Everything on the page comes from `demos.json`. Adding or
  changing a demo is a data edit, not a code change. If you add a field, update
  the `Demo` type in `app/demo-browser.tsx` and the field table in the README.
- **Structure.** `app/page.tsx` is a server component (header, intro, info
  cards). `app/demo-browser.tsx` is the `"use client"` component holding filter
  state and the cards. All styling is hand-written in `app/globals.css` using
  per-card `--tile-background` / `--tile-text` custom properties.
- **Design source.** The UI follows a Claude Design artifact. When it changes,
  match the artifact's layout and copy rather than inventing new styling. Its
  footer (Slack channel / last-updated placeholders) is intentionally not built.
- **Checks.** `npm run lint` and `npm run build`. Bare `npx tsc --noEmit`
  reports `Cannot find name 'LayoutProps'` because that type is generated by
  Next; the build's own type check is the reliable one.
- **Special entry.** The demo with `"industry": "Other"` is the "Coming soon"
  placeholder: always sorted last, never linked.
